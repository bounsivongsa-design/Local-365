# Local List 365 - Currituck County Directory

[![Tests](https://github.com/bounsivongsa-design/Local-365/actions/workflows/test.yml/badge.svg?branch=main)](https://github.com/bounsivongsa-design/Local-365/actions/workflows/test.yml)

Local List 365 is a community-focused platform for Currituck County, NC, connecting residents and visitors with local businesses and events. It features a comprehensive business directory, an event calendar, a quote request system, and AI-powered tools.

See [`replit.md`](./replit.md) for full project documentation, architecture, and development notes.
